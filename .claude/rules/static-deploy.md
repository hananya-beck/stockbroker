# Static deploy

This site is served as-is by GitHub Pages from `main` (https://hananya-beck.github.io/stockbroker/).

- No build step and no backend. `index.html`, `src/` and `data/` are served exactly as committed, so everything must run directly in the browser as native ES modules.
- Use relative paths only (`data/funds.json`, `src/styles/tokens.css`). The site lives under `/stockbroker/`, so a leading `/` breaks on Pages.
- The repo and site are public. Never commit tokens, keys or personal data. Secrets the page needs (such as the GitHub token for the refresh button) are typed in at runtime and kept in a JS variable only.
- No browser storage: no `localStorage`, `sessionStorage`, IndexedDB or cookies.
- `data/funds.json` is generated by `scripts/fetch_data.py` and committed daily by `.github/workflows/update-data.yml`. Don't hand-edit it. Pull before pushing, because the bot may have committed a newer copy.
- Run `npm run check` (typecheck, lint, JS tests) before committing front-end changes.
